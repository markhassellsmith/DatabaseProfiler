# Screenshot Guide

This folder contains screenshots used in the main README.md file.

## Required Screenshots

Please add the following screenshots to this directory:

### 1. object-browser.png
- **Page**: Object Browser
- **Content**: List of tables showing table names, schemas, row counts, column counts, and primary key indicators
- **Recommended size**: 1200px wide (height auto)

### 2. column-browser.png
- **Page**: Column Browser
- **Content**: Detailed column information for a selected table including data types, nullability, defaults
- **Recommended size**: 1200px wide (height auto)

### 3. data-profiling.png
- **Page**: Data Profiling page
- **Content**: Column statistics showing count, nulls, distinct values, min/max, and the expandable detailed statistics
- **Recommended size**: 1200px wide (height auto)

### 4. reports-confirm.png
- **Page**: Reports > Confirm
- **Content**: Table selection grid with checkboxes showing which tables will be included in the report
- **Recommended size**: 1200px wide (height auto)

### 5. excel-report.png
- **Content**: Example Excel report showing the Summary sheet with hyperlinks, or a detail sheet showing profiling data
- **Recommended size**: 1200px wide (height auto)

## Screenshot Tips

- Use a clean sample database with professional-looking table names
- Ensure good contrast (light or dark theme is fine)
- Capture at least 1920x1080 resolution, then scale down to ~1200px width
- Use PNG format for best quality
- Show realistic data (no test123, foo, bar examples)
- Include enough content to show features but not overwhelm

## After Adding Screenshots

Once all screenshots are added:
1. Update the README.md if you used different filenames
2. Commit the screenshots along with the README
3. Push to GitHub to see them render on the repository homepage
